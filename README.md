# PakWholesellers — Wholesale Men's Clothing Website

Official wholesale men's apparel e-commerce storefront for **PakWholesellers**, designed in a **Green and White** Pakistani textile heritage theme.

## Key Features
- **Green & White Wholesale Brand Identity**: Deep Pakistani Emerald Green (`#0D5C3A`) paired with Crisp White (`#FFFFFF`) and Mint Alabaster (`#F5FAF7`).
- **12 Wholesale Men's Apparel Products**:
  - Stitched Eastern Wear (Shalwar Kameez, Embroidered Kurta Pajama, Executive Kurta Sets, Retailer 12-Suit Bundles)
  - Waistcoats & 3-Piece Festive Combos
  - Unstitched Wholesale Fabrics (4.5m Egyptian Cotton & Spun Boski / Latha Rolls)
  - Western Casualwear (240 GSM Pique Polo Shirts, Oxford Button-Down Shirts, Selvedge Stretch Denim Jeans)
- **Interactive Product Cards with "Add to Cart" Button**:
  - Select **Color**, **Size / Wholesale Pack**, and **How Many (Quantity)** directly on every product card.
  - Automatic volume tier discounts (e.g., 3+, 10+, 25+ units) with live line-subtotal calculation.
  - Prominent **Add to Cart** button + 1-click direct WhatsApp order button on each product.
- **Cart Drawer & WhatsApp Redirect with Pre-Written Message**:
  - Slide-over Cart Drawer showing all added items, quantities, unit prices, and grand total.
  - Clicking **"Click to Buy on WhatsApp"** redirects to `https://wa.me/<number>?text=...` with a pre-written itemized order message containing:
    - **Product Name** & SKU
    - **How Many (Quantity)** & selected Size/Color
    - **Unit Price** & **Item Subtotal**
    - **Grand Total Wholesale Price** & optional Buyer/Shop details
  - Customizable Store WhatsApp Number directly in the top bar or Cart Drawer.

## Running Locally
```bash
npm start
```
Or open `index.html` directly in any browser / host via GitHub Pages.
